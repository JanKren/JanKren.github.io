BRAVA - Boiling Flow CFD for Nuclear Fuel Assemblies

CFD simulation development for boiling flows in nuclear fuel assemblies

The BRAVA project develops CFD simulation capabilities for boiling flows in nuclear fuel assemblies. This SwissNuclear-sponsored research focuses on computational methods for nuclear thermal hydraulics.

Project Overview

The project develops computational approaches for boiling flow simulations in fuel assemblies, addressing the multi-scale nature of boiling phenomena in nuclear fuel geometries.

Computational Approaches

Eulerian Approach

  • Space and time-averaged void fraction predictions
  • Capable of simulating entire fuel assemblies
  • Computationally efficient for full-scale simulations

Validation Framework

  • DEBORA benchmark validation
  • Fuel bundle configurations: 2×2 and 3×3 geometries
  • Operating conditions: NPP operational parameters

Applications

  • Safety analysis for nuclear facilities
  • Operational parameter optimization
  • T-Flows code enhancement
